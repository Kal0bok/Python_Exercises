# LVT Programming Fundamentals (Python)

Šajā repozitorijā ir apkopoti Liepājas Valsts tehnikuma (LVT) mācību uzdevumi un praktiskie darbi Python programmēšanas valodā.

## 🛠 Izmantotās tēmas un koncepti:
- **Sazarošanās un nosacījumi:** `if / elif / else`, datu tipu pārbaude.
- **Cikli:** `for`, `while`, darbs ar diapazoniem (`range`).
- **Datu struktūras:** Saraksti (`list`), Kopas (`set`), Vārdnīcas (`dict`).
- **Moduļi:** `datetime`, `random`.
